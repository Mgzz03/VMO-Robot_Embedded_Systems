========================================================= 
Project: VMO - Autonomous Home Pet & Safety Monitoring Robot 
Course: CIE 349 - Embedded Systems 
========================================================= 
 
This archive contains all documentation, software, and hardware design files for the VMO project. 
 
DIRECTORY STRUCTURE: 
-------------------- 
1_Report/ 
- Contains the 10-page Technical Documentation (PDF). 
 
2_Software_and_Firmware/ 
- Dockerfile: The environment blueprint for the ROS 2 container. 
- ESP32_Code/: The ESP32 FreeRTOS middleware and web-server code. 
- PIC_Code/: The hard real-time C code for the PIC16F877A. 
 
3_Hardware_and_Simulation/ 
- VMO_KiCad_PCB.zip: The complete PCB manufacturing design files. 
- VMO_Proteus_Simulation.pdsprj: The Proteus schematic and simulation file. 
 

4_Model/
- The model folder contains a short report about the vision model used and its role in the system.
- The report includes the official reference link with full technical details of the model.
- The ONNX file is not included in this submitted package.

Note on Source Code: 
This publishing copy is hosted in a private GitHub repository. Local Wi-Fi credentials are excluded; see README.md for setup and the package's current limitations.
